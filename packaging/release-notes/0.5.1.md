# radian 0.5.1

This release draws an ACP worker's conversation in the arc interface the way
a radian worker's conversation is drawn.

## arc

- **An ACP worker's conversation is a transcript.** The task page's
  conversation tab folds the stream of an ACP agent (Codex through
  codex-acp, or any other ACP agent) into messages and draws them with
  radian's transcript renderer and theme. Before, every streamed chunk was
  its own row, so an answer showed one token per line.
  - Message chunks join into one assistant message, drawn as markdown.
    Thought chunks join into one thinking block.
  - A tool call is one tool card, updated in place. A diff draws as a diff.
  - A plan draws as a list, replaced by the next plan.
  - Usage and session info updates are no longer drawn as JSON.
  - A permission answer is drawn after the tool it answers. String and
    number request ids both match.
  - The view keeps a fixed amount of memory.
- A command worker that does not speak ACP keeps the row view.

See `docs/user/arc/tui.md`.
