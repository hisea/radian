# radian 0.1.1

This release ships the full user manual inside the binary, and fixes two
footer configurations that failed without a sign and one `radian exec`
hang on a second Ctrl-C.

## The user manual

`radian docs` lists the manual's pages and `radian docs <topic>` prints one;
the agent reads the same pages through `radian://docs/`. The manual now
documents every input that changes radian's behavior, with its type, its
default, every allowed value, its limits and when it takes effect:

- `cli.md`: every command, subcommand and flag of `radian` and
  `radian exec`, with values, defaults, conflicts and exit codes.
- `configuration.md`: every configuration key in every section.
- `environment.md`: every environment variable radian reads, and the files
  whose presence or content changes behavior.
- `footer.md` (new): every footer item, its placeholders, its parameters,
  its icons per glyph set, thresholds, command items, and each built-in
  preset in full, exactly as `radian footer export <preset>` prints it.
- `commands.md`, `keybindings.md` (new), `hooks.md` (new),
  `context-files.md` (new), `extensions.md` (new), `mcp.md`, `themes.md`,
  `skills.md`, `memory.md`, `subagent-and-jobs.md`, `quickstart.md` and
  `index.md`.

Tests read the names, value sets and defaults from the code and fail when a
page falls behind.

Two pages were wrong in 0.1.0 and are corrected: a skill's frontmatter key
is `disable-model-invocation` (not `disable_model_invocation`), and the
`memory_search` tool's count field is `limit` (not `max_results`). A skill
file written from the old page had no effect.

`--help` text no longer carries internal history wording.

## Fixes

- Footer command items: a `command` (or `period`) written inline in a
  `[[tui.footer.rows]]` item was marked as a command item but never ran.
  It is now not read, and a warning tells you to move it to
  `[tui.footer.items.<id>]`. A `command` under a built-in item id (for
  example `[tui.footer.items.model]`) started a process whose output was
  never shown. It now starts nothing, and a warning names the id.
- `radian exec` listens for SIGINT with one persistent subscription, so a
  second Ctrl-C while the run winds down can no longer hang the process.
- `/memory import <path>` in the full-screen interface now reads the file.
  Before, it passed the path to the importer as if it were the Markdown, and
  the import always failed. A relative path resolves against the workspace;
  a path with `..` or through a symbolic link is refused.
- `/memory add -`, `/memory edit <id> -` and `/memory import -` in the
  full-screen interface write nothing and say that `-` reads stdin only in
  `radian memory`. Before, `/memory add -` stored a record whose text was
  `-`.

## Install

`brew upgrade radian` (or `brew install hisea/tap/radian`), a release
tarball (check it against its `.sha256`), or `cargo install` from source.
The targets and packaging are the same as 0.1.0.
