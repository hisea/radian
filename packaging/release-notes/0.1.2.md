# radian 0.1.2

A small fix release.

## Fixes

- A command whose output pipe closes early no longer panics. `radian docs`
  piped into `head` used to stop with `failed printing to stdout: Broken
  pipe`. Now `radian docs`, `radian docs <topic>`, `radian footer export`,
  `radian theme import` and `radian exec --fork` stop writing and exit 0 when
  the reader is gone, as `head` and `git` do; any other write error prints one
  line on stderr and exits 1. `docs/user/cli.md` states this.
- The `radian docs` unknown-topic message names the topic in matching
  backticks.

## Tests

- The test that a committed IME string reaches the input in one frame no
  longer depends on machine load. It failed once on a heavily loaded Mac
  because it measured 150 ms of wall-clock time. A unit test now checks that
  a buffered burst drains without one poll wait per event, and the terminal
  test checks that no frame shows part of the string.

## Install

`brew upgrade radian` (or `brew install hisea/tap/radian`), a release
tarball (check it against its `.sha256`), or `cargo install` from source.
The targets and packaging are the same as 0.1.1. The manual is at
<https://getrad.dev/docs/>.
