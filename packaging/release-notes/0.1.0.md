# radian 0.1.0

radian is a coding agent in one Rust binary, and the agent runtime it is
built on: `radian` opens a full-screen terminal UI, and `radian exec` runs
the same agent headless.

This first release ships the `radian` binary and its `rad` alias (two
separate binaries sharing one entry point), for four targets:

- macOS `aarch64-apple-darwin` and `x86_64-apple-darwin`, signed with a
  Developer ID certificate and notarized. Each is a
  `radian-<version>-<target>.tar.gz` holding `radian` and `rad`.
- Linux `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl`,
  statically linked (musl), so the same tarball layout runs on any distro
  regardless of its glibc.

Install from Homebrew (`brew install hisea/tap/radian`, which links only
`radian`: homebrew-core already has a `rad` formula), from a release tarball
(check it against its `.sha256`, unpack `radian` and `rad` inside), or from
source with Cargo. On Linux the `workspace` profile runs the sandbox through
`bubblewrap`, which must be installed first.

The release is licensed under either MIT or Apache-2.0. New users start with
`docs/user/quickstart.md`; the design is in `ARCHITECTURE.md`, and the
decisions that constrain the code are in `docs/adr/`.
