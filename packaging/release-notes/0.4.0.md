# radian 0.4.0

This release draws images in the transcript, lets one provider hold several
API keys, and makes the arc interface a full owner console: the board, the
merge page and the owner's actions. The arc scheduling loop is now
`radian arc serve`, and `radian arc mcp --claude-experimental` pushes task
transitions to Claude Code.

## Images

- **Images draw in the transcript** (ratatui-image), under their
  `[image: …]` line. An image takes half the transcript area's height, at
  least 12 and at most 40 rows, and the height follows a terminal resize.
- **`ctrl-v` attaches an image from the system clipboard.** The pixels are
  encoded to PNG in memory: nothing is written to disk and no path enters
  your message.
- Images in a tool result draw whatever the tool output's fold.
- A dropped macOS screenshot path (with the narrow no-break space before
  AM/PM) attaches.
- `read` of an image ignores `offset` and `limit`.
- Attachment rows sit inside the input frame, aligned with the text.

## Providers

- **Several API keys for one provider.** An `auth.json` entry keeps the first
  key as `key` and lists the rest in `keys`. A session keeps one key; an HTTP
  429 rests that key (for `Retry-After`, at most one hour, else five minutes)
  and the next request uses the next key, with one notice. `radian login`
  adds a key, `radian logout <provider> [name]` and `/logout` pick one, and
  the usage row names the key in use. See `providers.md`.

## arc

- **`radian arc serve` is the scheduling loop.** It replaces
  `radian arc run --watch`, which now exits `2` naming the new command. The
  loop replaces itself when its binary is rebuilt and says when main gained
  arc code.
- **The arc interface is the owner's console.** A board page (todo, doing,
  verifying and needs-you columns, and a finished list), a merge page, and
  the owner's actions: confirm, start, merge, reject, auto, pause, reverify,
  cancel and priority, with a confirmation before merge, reject, `auto merge`
  and cancel. The interface starts a `radian arc serve` loop when none runs.
  The task page has a brief tab and a live diff of the task's own change; the
  plans page filters by state (`f`) and sorts by priority, state or id
  (`o`). Tasks that need you are marked `!`. Esc goes back one level and `q`
  quits. It uses radian's theme from `config.toml`.
- **`radian arc mcp --claude-experimental`** pushes task and plan
  transitions to a Claude Code session over its channel extension. The MCP
  `update_task` tool changes a todo task's brief, title, `after`,
  `allow_noop` and `extra_stages`.
- **Gate and review:** a `critical` review item always blocks, and an item
  without a place is never demoted; a rework round demotes only items outside
  the task's whole change. `[gate.review] concurrency` and
  `[gate.review.first]` `exec_args` and `timeout_secs` tune the review. The
  review's follow-up task holds every round's suggestions, and a follow-up
  may deliver no change. arc proposes one follow-up per plan, once the plan
  has no task left in `todo.ready`, `doing` or `review`, instead of one per
  merged task. Tasks merged before the upgrade are never collected.
- **Recovery and limits:** `radian arc reverify` also re-runs a failed
  integration; a failed reverify does not count as an automatic rework.
  Every git call that waits on a remote has a limit
  (`[limits] git_remote_timeout_secs`, default `300`). `radian arc serve`
  stops when three passes in a row return the same error.
  `radian arc cancel` also ends a `failed.exhausted` or
  `failed.irrecoverable` task.
- **Cost:** review cost counts toward the budget, and tasks and plans show
  their cost totals.
- **Workers:** `.radian/arc/worker-brief.md` is appended to every brief, and
  every verdict a brief names is copied into the worker's worktree.
- `radian arc confirm --dry-run`; `show` prints the waits-on chain and the
  tasks a task blocks. `radian arc start` claims a `todo.retry_wait` task at
  once.

The arc manual moved to `docs/user/arc/` (`radian docs arc`): `index.md`,
`loop.md`, `gate.md` and `files.md` are the full reference.
