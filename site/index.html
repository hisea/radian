rad coding agent · rust · one binary编码 agent · rust · 一个二进制

A fast, efficient coding agent that works in parallel. 快而高效，能并行干活的编码 agent。

radian is one Rust binary. It reaches the prompt in about 100 ms, spends context on the lines a task needs, and lets a lead agent hand work to task agents that run side by side. radian 是一个 Rust 二进制。大约 100 ms 就到输入框，上下文只花在任务需要的那几行上；lead agent 可以把活分给几个任务 agent，同时跑。

/01 why radian为什么是 radian
◜ speed快

Quick to start, quick to come back.启动快，回来也快。

A native binary with no runtime to boot. Long builds and test runs go to the background and report when they finish, so the model keeps working.原生二进制，不用先拉起一个运行时。长的构建和测试放到后台，跑完自己回报，模型不用干等。

~100 ms to the prompt到输入框
~160 ms to resume 10k messages恢复 1 万条消息的会话
◝ efficiency高效

Context goes to the work.上下文花在活上。

Reads take line ranges. A budget guard watches the window and compacts before it overflows. Every agent shows its own tokens and cost.读文件按行号范围读。预算守卫盯着上下文窗口，快满之前先压缩。每个 agent 的 token 和费用都单独显示。

read by range · auto compaction
per-agent usage and cost按范围读 · 自动压缩
按 agent 显示用量和费用
◞ orchestration编排

One lead, many hands.一个 lead，几双手。

A lead splits the job and starts task agents in parallel, each in its own worktree and sandbox. How your project orchestrates is a set of files, and a script can take the lead.lead 把活拆开，并行起几个任务 agent，每个有自己的 worktree 和沙箱。项目怎么编排写在几份文件里，也可以换成你自己的脚本当 lead。

worktree per task · control socket
per-project agents and checks一个任务一个 worktree · 控制 socket
按项目定义 agent 和验收
◟

Under all three: every step goes to a journal you can resume and fork, every tool runs behind an OS sandbox, and only you can approve. 三者底下：每一步都写进可恢复、可 fork 的会话日志，每个工具都在操作系统沙箱后面跑，审批只能由你来给。

Timings: Apple M4, release build, sandbox check included, no network.时间数据：Apple M4，release 构建，含沙箱检查，不走网络。
