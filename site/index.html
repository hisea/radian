A fast, efficient coding agent that fits in your pipeline. 快而高效，放得进任何流水线的编码 agent。

radian is one Rust binary. It reaches the prompt in about 100 ms and spends context on the lines a task needs. Its headless command prints every step as a JSON line and exits with a code that says how it ended. radian 是一个 Rust 二进制。大约 100 ms 就到输入框，上下文只花在任务需要的那几行上；无头命令把每一步按 JSON 逐行输出，退出码说明它是怎么结束的。

/01 why radian为什么是 radian
◜ speed快

Quick to start, quick to come back.启动快，回来也快。

A native binary with no runtime to boot. A command that runs past 120 s moves to the background, and the model is told when it finishes, so it keeps working.原生二进制，不用先拉起一个运行时。前台命令跑过 120 秒就转到后台，跑完会通知模型，模型不用干等。

~100 ms to the prompt到输入框
~160 ms to resume 10k messages恢复 1 万条消息的会话
◝ efficiency高效

Context goes to the work.上下文花在活上。

Reads take line ranges. A budget guard watches the window and compacts before it overflows. The footer shows tokens and cost as you go.读文件按行号范围读。预算守卫盯着上下文窗口，快满之前先压缩。footer 里随时看得到 token 和费用。

read by range · auto compaction
usage and cost in the footer按范围读 · 自动压缩
footer 显示用量和费用
◞ orchestration编排

Built to be orchestrated.为被编排而生。

radian does not run other agents; it is built to be run by them. One prompt in through radian exec, every step out as a JSON line, and an exit code that tells completed from failed from out of budget. Inside herdr it reports working, idle or blocked by itself, and radian attach watches any session read-only. Parallel work stays inside one reply: several subagent calls run side by side.radian 不去调度别的 agent，它是为了被调度而做的。一句话从 radian exec 进去，每一步按 JSON 逐行出来，退出码分得清完成、失败和超出预算。在 herdr 里它自己报告 working、idle、blocked；radian attach 可以只读地看任何一个会话。并行只发生在一条回复之内：几个 subagent 调用同时跑。

exec --output jsonl · exit codes by outcome
herdr-ready · attach · control socket
◟

Under all three: every step goes to a journal you can resume and fork, the sandbox is a switch (one flag, or saved per project, and it can only narrow), and only you can approve. 三者底下：每一步都写进可恢复、可 fork 的会话日志，沙箱是一个开关（一个参数，或按项目保存，只能收窄），审批只能由你来给。

Timings: Apple M4, release build, measured 2026-10-16 with the sandbox check included, no network.时间数据：Apple M4，release 构建，2026-10-16 测得，含沙箱检查，不走网络。

/02 headless无头

Headless, observable.无头，看得见。

One prompt in, the journal out: a JSON line per step and the outcome on the last line. It is the same session file, so a script can stop halfway and you pick it up in the full-screen app.一句话进，journal 出：每一步一行 JSON，最后一行是结局。同一个会话文件，脚本跑到一半，可以在全屏界面里接着跑。

watch · read-only只读地看radian attach <session> --follow
pick it up接着干radian --resume <session>

Inside herdr, radian reports working, idle and blocked by itself, and nothing about commands, paths or content.在 herdr 里，radian 自己报告 working、idle、blocked，不报命令、路径和内容。
