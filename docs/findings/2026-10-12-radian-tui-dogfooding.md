| D2 | That failed start still created the session file. For `--resume` nothing is written by a failure. MCP **process** startup happens when the tool session opens, after the file exists: the file is kept and the error names the way to continue with `--resume`. Tested by the same two tests plus `a_bad_mcp_config_leaves_no_session`, `pty_a_bad_mcp_config_creates_no_session`, `a_failed_probe_leaves_no_session_and_the_retry_creates_one`, `pty_a_failed_probe_leaves_no_session_and_the_retry_creates_one`. |
