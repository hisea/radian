# 摘要更新改成重写合并，不再滚动追加

- 状态：decided（2026-10-31）
- 涉及 ADR：0018（§摘要）
- 来源：2026-10-31 本地线路 TK0226 k=2 的摘要雪球（3734 → 6147 tok，撞上限后连续 12 次回退）；opencode 2.2.5 的做法（PR #48058：旧摘要每次更新都变长，改成一份合并摘要，"新历史优先"）

## 决定

- 摘要系统提示的更新规则从"滚动更新，追加新事实"改成：输出**一份**覆盖全部历史的合并摘要；上一份摘要是输入之一，不是要保留的文本；新历史与旧摘要矛盾时新历史优先；不再相关的条目删除。"Verified facts" 一节保持按时间顺序，仍可删最旧的。
- 长度上限的句子保留；缩短重试和回退截半（已落地）不变。
- 变化只在 `crates/radian-core/src/compaction.rs` 的提示常量和相关测试；ADR 0018 §摘要一句话。无用户输入变化，手册不改。

## 验收

- 单元测试断言提示里有"一份合并摘要"和"新历史优先"的稳定子串，没有"追加"的旧子串。
- 回放测试：喂一份 6k 的旧摘要 + 少量新历史，模型桩返回的摘要按新提示检查（现有 `check_summary` 路径）。
- 本地 32k 复跑：连续更新的摘要 token 数不单调增长；回退次数相对 2026-10-31 本地轮下降。
