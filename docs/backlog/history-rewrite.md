# 公开前改写 git 历史

- 状态：decided（依赖 `public-release-tree.md` 与 `adr-english-ste.md` 先落地）
- 涉及 ADR：无
- 来源：仓库公开前的检查清单

## 背景

当前树清理完后，历史里仍然留着：旧版本的中文 ADR 与它们的修订过程、决策记录（"owner" 与日期）、内网地址与本机路径（约 54 行），以及提交信息里同样的字样。远端只有 `main` 一个分支，仓库还是私有，没有 fork，此时改写代价最小。

## 决定（已定）

1. **暂停点**：改写前不再派新任务；所有进行中的分支要么合进 `main`，要么丢弃。改写后三台机器上的 worktree 与 worker 二进制全部重建。
2. **工具**：`git filter-repo`，在一个全新的镜像克隆上做，不在工作仓库上做。
3. **ADR**：`docs/adr/` 从所有旧提交里删除；最终的英文 ADR 在改写后的最新处由一个提交加入。代码历史保留，ADR 在历史里只出现一次。
4. **文本替换**（所有文件、所有历史版本，包括 `research/`）：内网地址、`user@host`、`/Users/<name>/`、`/home/<name>/` 换成与当前树相同的占位符；"owner" 加日期、"决定/定"一类决策记录去掉。规则写成 `--replace-text` 的表达式文件，先在副本上试跑，统计每条规则的命中数再定稿。
5. **提交信息**：同样的规则用 `--replace-message` 处理（约 241 条提交标题含 "owner"）。
6. **作者**：保持不变。
7. **force-push**：验证通过后，再问一次维护者，确认后才 force-push `main`。

## 验收

- 改写前后各跑一次 `gitleaks git`：只剩 `.gitleaksignore` 放行的 3 处测试假密钥。
- 改写后的历史里：`git log --all -p` 搜不到内网地址、本机路径、"owner 20"、"修订"；`docs/adr/` 只在最新提交里出现。
- 改写后最新提交的树与改写前最新提交的树相同，只差替换规则造成的差异（脚本比对）。
- 改写后的最新提交上 AGENTS.md 的 Verify 全部通过。
- force-push 后三台机器上的 worktree 与 worker 二进制已重建，下一个 gate 正常运行。
