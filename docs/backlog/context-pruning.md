# 轻量档：先清被取代的旧工具输出，再做摘要

- 状态：idea（只在 `compaction-threshold.md` 的 A/B 拿不到足够收益时才做）
- 涉及 ADR：新 ADR（清理是一种 transcript 替换：与 0019 的提交、0036 的缓存前提、0018 的阈值如何配合）
- 来源：`research/2026-10-18-area-deep-dive/3-context.md` §6.4；先量数据再定

## 背景（已量，本机 158 个会话、2026-10-20）

- 工具结果占消息字节的 61%（assistant 39%，用户 0%）；其中 `read` 48%、`shell` 26%、`grep` 20%。
- `read` 共 3,185 次、19.2 MB。其中 **1,561 次、9.4 MB 的结果后来被同一路径的再次 `read` 取代**，占 read 字节的 49%、全部工具字节的 24%。这就是 omp「被新读取取代的先清」这一条规则能省下的上限（粗算：同一路径的后一次 read 不论 offset/limit 都算取代，所以略偏高）。
- 158 个会话只压缩过 1 次（窗口 1M 的模型），所以这项的收益不是"推迟摘要"，而是把每次调用拖着的 prompt 变小：prompt >300k 时每次调用 p50 5.2 s，<50k 时 2.8 s。
- 缓存命中 98.7%，每次清理都会重写被改动位置之后的前缀，所以要有门槛（omp：保护最近 40k，至少能省 20k 才动，离末尾不到 8k 的不动；Anthropic `clear_at_least`）。
- A/B ab7 的 radian 会话又是一例：`migrate_claude.rs`（2,000 多行）读了 18 次，976 行起读了 3 次、1511 行起 2 次；prompt 第 50 次调用 206,705 token、第 196 次 327,025，中间没压缩。read 占这轮工具结果字节的 72%（430 KB / 596 KB），这一个文件占 20%。
- 但这 18 次读的范围大多不重叠：按行次算共读过 4,202 行次，2,732 行只读过一次，1,470 行读过两次以上。「同路径后一次 read 取代前一次，不论范围」在这里会清掉模型还要用的内容，逼它重读；能省的只有重叠的约四分之一。规则必须按范围算（见待决方向 1）。

- 另一批 39 个 worker 会话（5125 次工具调用，几乎全是 deepseek-v4.1-flash）再量一次：`read` 1254 次、11.4 MB，占工具字节的 66%；同一路径被再次 `read` 的 424 次、3.5 MB（31%），但**旧结果的行范围被后来一次 `read` 完全覆盖的只有 20 次、44 KB**。模式是先整读前 500 行（缺省 `limit`），再按范围补读后面，后读几乎不覆盖先读。所以按范围算的第一条规则在这批数据上几乎省不到东西；要省到那 3.5 MB，规则得是"同路径的旧结果被新结果取代，不论范围"，而那正是 ab7 证明会逼模型重读的做法。39 个会话 0 次压缩，最大 prompt 481k。

## 做的条件

1. `compaction-threshold.md` 的 A/B 已经跑过，结论是延迟收益不够或压缩代价太大。
2. 能回放测清理前后的缓存命中率（journal 有 `cache_read`，这一点现成）。每次清理会让改动点之后的前缀失去缓存，那一次请求要重新 prefill 几十万 token，可能一次吃掉十几次调用省下的时间；门槛能否打平这笔账要有数据。
3. 新 ADR 先定「在 transcript 里替换（走 0019 提交）还是只在投影到请求时省略」。

收益的量级：被取代的 read 占工具字节 24%，工具字节占上下文 61%，所以 prompt 只缩约 15%；按实测延迟曲线（6 倍大小差 2.4 s）约合每次调用 0.3–0.5 s。

## 待决方向

1. 第一条规则只做「同一路径被后来的 `read` 取代的旧结果换成占位 `[superseded by a later read of <path>]`」，保留工具调用参数。它确定性、不调模型、不丢任何模型还没见过的内容。 「取代」按范围算：只有旧结果的行范围被后来一次 `read` 完全覆盖才算；部分重叠的保留。ab7 的 18 次读里只有约四分之一的行次重叠，不按范围算会逼模型重读。
2. 门槛与保护窗口照 omp 的三个数起步，用 dogfood 调。
3. 更广的「清所有旧工具输出」（shell/grep）放第二步，等第一步的数据。
4. 实现可复用确定性兜底里的 `truncate_kept_tool_results`（`crates/radian-core/src/compaction.rs`）；提交走 ADR 0019 的 transcript 替换，`journal-selfcheck` 必须过。

## 验收

- 长会话回放：清理后的总输入 token 下降，每次调用延迟下降；缓存命中率不低于清理前 2 个百分点（门槛生效的证据）。
- 变异：保护窗口失效、门槛失效、清掉了最新一次 read，各有测试失败。
