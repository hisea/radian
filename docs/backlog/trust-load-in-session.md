# 信任后当场装载项目资源（TUI）

- 状态：idea（B2 先按现状合并，当场装载另记）
- 涉及 ADR：0031（T3 生效时机）、0004（边界生效）、0025（项目 skill）、0008 §8（MCP 配置）
- 来源：MCP B2 review（`dogfood/mcp-b2`）

## 背景（已核实）

- `radian exec` 在打开会话之前问信任，所以选了信任的那次进程就装载项目 skill 与项目 `.mcp.json`。
- TUI 在打开会话之后才弹信任窗口：用户选了信任，项目 skill 与 `.mcp.json` 里的 server 要到**下次启动**才装载；弹窗文字是「受信任后加载」。这符合 ADR 0031 T3 现行的生效时机（装载是边界生效的配置），但用户刚点了信任却看不到 server，容易以为没生效。

## 待决问题

- TUI 信任之后是否在当前会话里装载：启动项目 `.mcp.json` 的 server、把项目 skill 加进清单（工具表与系统提示都变，影响缓存前缀，ADR 0018）。
- 只在首次信任（弹窗）时当场装载，还是 `/trust on` 也当场装载；`/trust off` 维持「下次启动不再加载」。
- 当场装载失败（server 起不来）如何呈现。

## 验收（定了方向后）

- TUI 弹窗选信任后，同一会话里项目 MCP 工具出现在请求的 schema 里、项目 skill 出现在清单里；不信任时都不出现。
