# ADR 改写为英文 ASD-STE100

- 状态：decided
- 涉及 ADR：全部（0001–0047 中现存的 44 篇）
- 来源：仓库公开前的检查清单

## 背景

ADR 现在是中文，夹着决定日期、"修订 N" 标签、"旧做法是……" 一类的版本记录。仓库公开后，ADR 是外部贡献者理解约束的主要入口，应该是英文、只写现行决定。历史里的旧版本由 `history-rewrite.md` 处理：改写后 ADR 只以最终形式出现一次。

## 决定（已定）

1. **语言**：英文 ASD-STE100。短句，一句一事，主动语态，用 STE 的核准词表；技术名词（crate、类型、命令、配置键）照原样。
2. **只写现行决定**：删掉日期、"owner"、"修订 N / revision N"、"旧做法"、"改为"、变更表。被推翻的方案如果对理解有用，写成一句 "Rejected: …"，不写它曾经是决定。
3. **编号不变**：ADR 编号、文件名中的编号、小节编号（例如 L5、D11、U10、§4）保持不变，这样代码与文档里对 ADR 的引用不会失效。文件名的中文部分改成英文短名（编号不变）。
4. **内容不变**：改写不改变任何决定。每篇由审查者对照中文原文逐段核对：决定、例外、数值、验收要求一项不能多也不能少。原文前后矛盾的地方不擅自取舍，列出来交给审查者。
5. **代码引用同步**：代码注释与文档里的 "ADR NNNN revision N"、"ADR NNNN 修订 N" 改成 "ADR NNNN"（需要时带小节编号）。
6. **AGENTS.md 的 ADR 索引**：改成英文，每篇一个短标题，与新文件名一致。

## 分工

按编号分成约 4 组，每组约 11 篇，每组一个分支、一个 worker；每组两个提交：ADR 改写（docs-only），引用同步（只改注释与文档）。

## 验收

- `docs/adr/` 里没有中文字符、日期、"owner"、"revision"/"修订"。
- 每篇的小节编号集合与原文相同（脚本比对）。
- `git grep -E 'ADR [0-9]{4} (revision|修订)'` 为空。
- 每篇有审查记录：对照原文无遗漏、无新增。
- AGENTS.md 的 Verify 全部通过。
